# Introduction

**HARVEST is a permissioned Proof-of-Authority (PoA) sidechain for the Cardano ecosystem**, and the
**HARVEST DAO** that governs its treasury.

A sidechain is a separate chain that runs alongside Cardano rather than replacing it. HARVEST is designed to
carry two things: the **HRV token**, and a collection of **3,125 NFTs** — both of which can be moved between
the two chains.

## The pieces

- **[HRV](/docs/hrv-token)** — a Cardano native token. It is locked on Cardano mainnet and represented on the
  sidechain. The sidechain never mints its own.
- **[The NFTs](/docs/nfts)** — 3,125 of them, in five tiers, moved the same way.
- **[Node Handlers](/docs/node-handlers)** — the authorised validators that produce blocks, in round-robin
  order, on modest hardware.
- **[Governance](/docs/governance)** — proposals, quadratic voting, and a multi-signature treasury.
- **The chain itself** — Plutus-based, written in Aiken, built with the Cardano Sidechain Toolkit.

## Where the project is

The design is documented. The software is not built. There is no sidechain to connect to, no node to run, and
no bridge to move tokens across.

**[Project status](/docs/status) sets out exactly what exists and what does not, and is worth reading before
anything else here.**

Two things follow from that, and they matter:

- **HRV has no value today.** The DAO treasury is unfunded.
- **Nothing on this site is an offer, a price, or financial advice.** HARVEST is an early-stage project being
  built in the open.
