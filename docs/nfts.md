# The NFTs

HARVEST includes a collection of **3,125 NFTs**, moved between Cardano and the sidechain the same way HRV is:
locked on one side, represented on the other.

## The collection

- **3,124 NFTs** make up the collection proper.
- **NFT #0000** stands apart from it, and is the project's Discord icon.

The collection is organised into five tiers: **Bronze, Silver, Gold, Platinum and Legacy.**

## What they are intended to carry

Each NFT is intended to hold rewards and a governance role, alongside a real-world link. None of that is
implemented: the collection has not launched, and the sidechain that would hold it does not exist yet. See
[Project status](/docs/status).
