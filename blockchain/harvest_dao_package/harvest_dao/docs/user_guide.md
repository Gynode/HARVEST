# HARVEST DAO User Guide

This guide provides a step-by-step walkthrough of how to participate in the HARVEST DAO, from setting up your wallet to casting your first vote.

## 1. Getting Started

To participate in the HARVEST DAO, you will need the following:

*   A compatible crypto wallet (e.g., MetaMask, Trust Wallet)
*   HRV tokens to use for voting and proposal creation

### 1.1. Setting up Your Wallet

1.  Install a compatible wallet from the official website or app store.
2.  Create a new wallet and securely store your seed phrase.
3.  Add the HARVEST sidechain network to your wallet.

### 1.2. Acquiring HRV Tokens

You can acquire HRV tokens through the following methods:

*   **Node Handler Rewards:** Become a Node Handler and earn HRV tokens as rewards for validating transactions.
*   **Community Airdrops:** Participate in community events and airdrops to receive free HRV tokens.
*   **Decentralized Exchanges (DEXs):** Purchase HRV tokens on supported DEXs.

## 2. Using the Governance Interface

The HARVEST DAO governance interface is a user-friendly web application that allows you to interact with the DAO.

### 2.1. Connecting Your Wallet

1.  Go to the HARVEST DAO governance website.
2.  Click on the "Connect Wallet" button.
3.  Select your wallet provider and approve the connection.

### 2.2. Dashboard

The dashboard provides a comprehensive overview of the HARVEST DAO, including:

*   **Key Metrics:** Treasury value, active members, active proposals, and voting power.
*   **Treasury Growth:** A chart showing the historical growth of the DAO treasury.
*   **Asset Allocation:** A breakdown of the treasury's asset allocation.
*   **Recent Proposals:** A list of the latest governance proposals and their status.

### 2.3. Proposals

The proposals section allows you to view and create governance proposals.

*   **View Proposals:** Browse through the list of all proposals, including active, passed, and rejected ones.
*   **Create a Proposal:** If you meet the proposal threshold, you can create a new proposal by providing a title, description, and execution details.

### 2.4. Voting

The voting section is where you can cast your votes on active proposals.

*   **Active Proposals:** View the list of all proposals that are currently open for voting.
*   **Cast Your Vote:** For each proposal, you can cast your vote as "yes," "no," or "abstain."
*   **Voting Power:** Your voting power is determined by the number of HRV tokens you hold.

### 2.5. Treasury

The treasury section provides detailed information about the DAO's treasury.

*   **Treasury Overview:** View the total value of the treasury, yield generated, and operating expenses.
*   **Asset Allocation:** See how the treasury's assets are allocated across different categories.
*   **Yield Strategies:** Learn about the different yield-generating strategies being used to grow the treasury.
*   **Recent Transactions:** Track the latest treasury operations and movements.

### 2.6. Governance

The governance section allows you to view the DAO's parameters and roles.

*   **Parameters:** View the current governance parameters, such as the proposal threshold, voting period, and quorum.
*   **Node Handlers:** See the list of authorized Node Handlers for the HARVEST PoA network.
*   **Treasury Committee:** View the members of the multi-signature treasury committee.
*   **Change History:** Track the history of all governance parameter changes.

## 3. Delegating Your Voting Power

If you don't have the time to actively participate in governance, you can delegate your voting power to another address that you trust.

1.  Go to the governance interface and connect your wallet.
2.  Navigate to the "Delegation" section.
3.  Enter the address you want to delegate to and confirm the transaction.

## 4. Becoming a Node Handler

If you are interested in playing a more active role in the HARVEST ecosystem, you can apply to become a Node Handler.

1.  Review the hardware and staking requirements for Node Handlers.
2.  Submit an application through the governance interface.
3.  If your application is approved, you will be added to the set of authorized validators.
